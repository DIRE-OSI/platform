# Support & Contact

Thanks for your interest in DIRE. Here's how to get help, ask questions, or report a problem — and where each kind of request should go.

## Where to go

| I want to… | Use this |
|---|---|
| **Report a bug, error, or reproducibility gap** | Open a [**GitHub Issue**](https://github.com/DIRE-OSI/platform/issues/new/choose) using the *Bug report* template |
| **Ask a question, propose an idea, discuss a covariate/disease/country** | Start a [**GitHub Discussion**](https://github.com/DIRE-OSI/platform/discussions) |
| **Request a feature or research addition** | Open an [**Issue**](https://github.com/DIRE-OSI/platform/issues/new/choose) using the *Feature request / research idea* template |
| **Report a security vulnerability** | Follow [**SECURITY.md**](SECURITY.md) — please do **not** open a public issue |
| **Give feedback on the live dashboard** | Use the **feedback form on the live site**: <https://dire.impact.nltglobal.com> |
| **Discuss a data partnership, validation study, or country expansion** | See [**docs/TEAM.md**](docs/TEAM.md) |

## How we respond

New issues are automatically acknowledged and routed to the DIRE-OSI maintainers (New Light Technologies) for review. Because the platform is in **active development and beta**, response times may vary and some known issues are already being addressed — please check existing issues and discussions before opening a new one.

## Please include

When reporting a problem, it helps to include: what you expected, what happened, steps to reproduce, and your environment (OS, Python/R version, component). **Never include secrets, credentials, or personal/locational health data.**
