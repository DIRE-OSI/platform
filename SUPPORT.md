# Support & Contact

Thanks for your interest in DIRE. This repository is the public home for DIRE: documentation, release notes, feedback and questions all live here. Here's where each kind of request should go.

## Where to go

| I want to… | Use this |
|---|---|
| **Give feedback on the live dashboard, or report a problem with it** | Open a [**Dashboard feedback**](https://github.com/DIRE-OSI/platform/issues/new?template=dashboard_feedback.yml) issue (English, Spanish or Portuguese). The dashboard's "Submit Feedback" link opens the same form. |
| **Report a bug, error, or reproducibility gap in the code or docs** | Open a [**GitHub Issue**](https://github.com/DIRE-OSI/platform/issues/new/choose) using the *Bug report* template |
| **Ask a question, propose an idea, discuss a covariate/disease/country** | Start a [**GitHub Discussion**](https://github.com/DIRE-OSI/platform/discussions) |
| **Request a feature or research addition** | Open an [**Issue**](https://github.com/DIRE-OSI/platform/issues/new/choose) using the *Feature request / research idea* template |
| **See what changed in the dashboard** | Read the [**Releases**](https://github.com/DIRE-OSI/platform/releases). To be notified of new versions, choose *Watch, then Custom, then Releases* on this repository. |
| **Report a security vulnerability or anything confidential** | Follow [**SECURITY.md**](SECURITY.md) and use the private report. Please do **not** open a public issue. |
| **Discuss a data partnership, validation study, or country expansion** | See [**docs/TEAM.md**](docs/TEAM.md) |

A free GitHub account is needed to open an issue or discussion. Everything posted here is public.

## How we respond

New issues are automatically acknowledged and assigned to the DIRE-OSI maintainers (New Light Technologies) for review. Because the platform is in **beta**, response times may vary and some known issues are already being addressed. Please check existing issues and discussions before opening a new one.

## Please include

When reporting a problem, it helps to include: what you expected, what happened, steps to reproduce, and, for the dashboard, the country, disease, administrative level and month you were viewing. **Never include secrets, credentials, or personal/locational health data.**
