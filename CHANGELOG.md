# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased] — planned as v0.1.0

First tagged, citable release of the DIRE open-science repository. *Draft release notes; not yet tagged.*

### Added
- Documentation site with navigation, search and a refreshed home page.
- **Methods & model card**: modelling approach, evaluation design, outputs, limitations and intended use.
- **Research basis**: scientific foundations, data foundations, resource-estimation overview and citation guidance.
- **Data dictionary** for analysis-ready inputs and forecast outputs, and a provenance summary for each data source.
- **Test data** page describing the synthetic, schema-faithful datasets planned for credential-free runs.
- Community and governance files: license (Apache-2.0 for code, CC BY 4.0 for documentation), contributing guide, code of conduct, security and support policies, citation metadata.

### Changed
- Consistent naming: **DIRE — Disease Incidence and Resource Estimator** across all documents.
- Documentation links made robust for both GitHub and the published site.
- Dashboard guide refreshed for the beta notice, EN/ES/PT languages and known issues.

### Fixed
- Broken internal links and the weekly documentation link check.

### Not yet included
- Pipeline source code, synthetic test data and the quick-start notebook (see [Roadmap](docs/ROADMAP.md)).
- Archival DOI (minted on first release; see [RELEASING.md](RELEASING.md)).
