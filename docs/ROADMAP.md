# Roadmap

DIRE is released in phases so that each public artifact is curated, reviewed, and safe to share. This document describes the planned sequence. Dates are indicative and may shift as the project and its community priorities evolve.

## Phase 0 — Open documentation & pipelines *(current)*

- Data-source documentation (credentials, licenses, coverage)
- Python/R processing pipelines for covariates and forecasting
- Bundled aggregate, non-personal test data for reproducibility
- Community-health and governance files (license, contributing, code of conduct, security)

## Phase 1 — Reproducible local runner

- Prediction API / backend service (source)
- Containerized one-command local runner
- Automated test suite and continuous integration
- Resource-estimation outputs

## Phase 2 — Dashboard source

- Interactive dashboard source code (Cases, Resources, Model Indicators views)
- Model performance and indicator outputs

## Phase 3 — Archival & scale

- Cloud deployment / infrastructure-as-code reference
- Zenodo DOI archive of tagged releases
- Additional countries and diseases as data agreements allow

## How the community shapes the roadmap

This roadmap is a starting point, not a fixed contract. We prioritize based on what researchers and public-health users tell us they need. Open a [discussion](https://github.com/DIRE-OSI/platform/discussions) to propose priorities, and see [Get Involved](https://github.com/DIRE-OSI/platform/blob/main/README.md#-get-involved) for how to participate.
