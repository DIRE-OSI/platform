# DIRE — Disease Incidence and Resource Estimator
{: .fs-9 }

Open documentation for sub-national **dengue and malaria forecasting** and **health-resource estimation** in Peru and Brazil — the current month plus the following two.
{: .dire-lede }

[Open the live dashboard](https://dire.impact.nltglobal.com){: .btn .btn-primary .mr-2 }
[View on GitHub](https://github.com/DIRE-OSI/platform){: .btn .mr-2 }
[Methods & model card](METHODS.md){: .btn }

---

## What DIRE does

- **Forecasts** monthly disease incidence for administrative units at three levels, for three horizons.
- **Ranks** units into five relative risk tiers and flags low-confidence estimates.
- **Estimates** indicative prevention, diagnosis, treatment and program resource needs from expected cases.
- **Opens** its methods, documentation and pipelines for review, reuse and reproduction.
